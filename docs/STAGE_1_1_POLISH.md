# Stage 1.1 — Book Shell Polish

Scope: visual polish only. No learning-content redesign and no changes to Supabase or pedagogy.

Approved improvements:
- Add a darker secondary paper-frame layer under the live pages to create visible page-stack depth.
- Strengthen the physical book shadow and central gutter without distorting content.
- Tuck desktop chapter tabs partially beneath the book edge so they read as bookmarks, not floating cards.
- Reposition previous/next sliced-button controls so they emerge from the book edge and retain a large accessible hit target.
- Reduce desk-background competition with a subtle overlay/vignette.
- Tighten mobile brand spacing and move the book upward.
- Restyle mobile chapter navigation as paper bookmarks attached to the lower book edge while keeping direct access to all five chapters.
- Preserve the single-page mobile model and the two-page desktop model.

New runtime assets used in this polish:
- `Plain/1 Paper/27.png` through `34.png` as the darker secondary page-stack frame set.
